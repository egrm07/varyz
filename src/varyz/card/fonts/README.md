# Card fonts

Cut-down static copies of three open fonts, used to paint the card PNGs:

| File | Cut from | Licence |
|---|---|---|
| `VaryzCardSerif-Regular.ttf` | Source Serif 4, weight 400, optical size 60 | `OFL-SourceSerif4.txt` |
| `VaryzCardSerif-Italic.ttf` | Source Serif 4 Italic, weight 400, optical size 40 | `OFL-SourceSerif4.txt` |
| `VaryzCardSans-Regular.ttf` | IBM Plex Sans, weight 400 | `OFL-IBMPlexSans.txt` |
| `VaryzCardSans-SemiBold.ttf` | IBM Plex Sans, weight 600 | `OFL-IBMPlexSans.txt` |
| `VaryzCardDisplay-Regular.ttf` | Marcellus, weight 400 | `OFL-Marcellus.txt` |

Each keeps only Latin and Latin Extended. All three fonts are under the SIL Open Font
License 1.1. IBM Plex reserves the name "Plex" and Marcellus its own name, so these
modified versions carry the names "Varyz Card Serif", "Varyz Card Sans" and "Varyz Card
Display". Built by `scripts/build_card_fonts.py` from the fonts in github.com/google/fonts.
