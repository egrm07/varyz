# Taste Card fonts

Cut-down static copies of two open fonts, used to paint the `varyz wrapped` PNG:

| File | Cut from | Licence |
|---|---|---|
| `VaryzCardSerif-Regular.ttf` | Source Serif 4, weight 400, optical size 60 | `OFL-SourceSerif4.txt` |
| `VaryzCardSerif-Italic.ttf` | Source Serif 4 Italic, weight 400, optical size 40 | `OFL-SourceSerif4.txt` |
| `VaryzCardSans-Regular.ttf` | IBM Plex Sans, weight 400 | `OFL-IBMPlexSans.txt` |
| `VaryzCardSans-SemiBold.ttf` | IBM Plex Sans, weight 600 | `OFL-IBMPlexSans.txt` |

Each keeps only Latin and Latin Extended. Both fonts are under the SIL Open Font License
1.1. IBM Plex reserves the name "Plex", so these modified versions carry the names
"Varyz Card Serif" and "Varyz Card Sans". Built by `scripts/build_card_fonts.py` from the
variable fonts in github.com/google/fonts.
