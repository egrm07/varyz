# Varyz Shared

**Consult projects explicitly shared with your verified Varyz account, ask
their owner missing decisions, and work on the same code through GitHub.**

Accept the owner's invitation first. Connect this plugin using native Varyz
sign-in, then select a collaboration in a fresh task. Guest consultation requires
no subscription. The owner needs active Cloud access to serve its publications.

| Resource | Scope |
| --- | --- |
| `https://cloud.varyzai.com/mcp/shared` | `varyz.shared` |

| Tool | Purpose |
| --- | --- |
| `shared_projects` | List your collaborations and pending invitations |
| `shared_join` | Accept an invitation from an owner who added you by username |
| `shared_brief` | Select a task's collaboration and read reviewed publication pages |
| `shared_ask` | Ask missing decisions or read exact published answers |
| `shared_question_status` | Retrieve your own question states and replies |
| `shared_finish` | Report your work and check coverage and open questions |
| `shared_github` | Report repository access checks and get the next step |
| `shared_answer` | Decide partners only: record a partner's answer to a project question |
| `follow` | Follow a creator's public Varyz by username, pick one per topic, list, read standards |
| `followed_brief` | The followed standards that fit a task, one creator per topic |
| `followed_ask` | A followed creator's published answer to a preference question |

Following a public Varyz (cloud.varyzai.com/@username) is free; the creator
needs active Cloud access to serve it. Followed standards are someone else's
published standards: your own instructions win where they differ.

Private preferences and history are excluded. Published data does not authorize
spending, messaging or deployment. Revocation ends future reads, including reply
retrieval. Native connection success requires an actual shared tool result;
package installation alone is insufficient.
