# Varyz

Stop repeating how you like things done. Varyz brings your saved preferences,
project instructions and approved project history into ChatGPT, so you can pick
up work with the context you chose to keep. Write and edit in your preferred
tone, style and format; follow saved project requirements; find why a decision
was made and what changed; or remember an instruction you explicitly ask to save.

Varyz includes the hosted tools and task skills in the same plugin. Connect an
existing Varyz Cloud account through its native OAuth sign-in and consent step;
no separate Varyz Cloud plugin installation is part of setup. The connector at
`https://cloud.varyzai.com/mcp/plugin` reads and updates confirmed rules, answers and
workflows and retrieves already approved, synced history. Retrieved passages and
preferences are shared with the AI provider you connect. Saving a rule requires
your explicit instruction; an excerpt never becomes a preference automatically.

History tools are read-only. The plugin cannot upload records, select or approve
projects, change billing, delete your account or read arbitrary phone/laptop files.
Only eligible documents, AI conversations, Git and GitHub records approved for
sync are available; WhatsApp and Telegram are excluded. Local installation, source
selection, preference sync and project/General history approval are separate choices.
Your computer may be off after sync; new work waits for another local sync.

Try “Use my saved writing preferences to draft a reply”, “Why did we choose this
approach for my project?”, or “Where did we leave my project, and what changed?”
Use your own project name outside the review account. Answers cite available
evidence and explain missing context. If disconnected, the skills can apply what
you provide in the current chat without claiming to save it across chats.

The optional local companion has additional indexing, hooks and background
processing. This hosted plugin provides remote tools and skills; invocation depends
on the host. It does not claim identical local retrieval rankings or public-directory
approval. No installer, command, hook, analytics script or checkout runs in this
package. Tool calls go only to Varyz Cloud and do not accept arbitrary destination URLs.
